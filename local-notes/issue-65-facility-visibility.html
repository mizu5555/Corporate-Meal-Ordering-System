Issue 65 - 廠區標籤與員工商家可見性

Branch: issue-65-facility-visibility Base: main @ 6b1f594 Issue: #65

這次解決什麼

系統原本有商家的 vendor_facilities，但沒有員工端的廠區歸屬。 本次新增 employee_facilities，並把員工端瀏覽、查看菜單、下單與隨機餐點都收斂到 「員工廠區與商家服務廠區有交集」才可見。

DB 變更

  • 新增 backend/db/migrations/006_employee_facility_visibility.sql。
  • 新增 employee_facilities(user_id, facility_id) 關聯表。
  • 補上 idx_employee_facilities_facility_id 索引。
  • Seed demo 廠區 F12A、F14B。
  • Demo employee 與 Sunny Kitchen 都綁到 F12A，確保預設資料可正常瀏覽。

後端行為

  • Repository 新增員工廠區指派與 list_for_employee 查詢。
  • GET /employee/vendors 只回傳同廠區核准商家。
  • 商家詳情與菜單若跨廠區，回 404 not_found。
  • 下單、選餐、更新訂單會檢查目前員工是否仍可見該商家。
  • Random meal draw 只會從員工可見商家挑餐點。

測試案例

  • 同廠區員工可以看到核准商家。
  • 沒有廠區的員工看不到商家。
  • 跨廠區商家詳情與菜單會被隱藏。
  • 跨廠區下單會被拒絕。
  • Repository 會依員工/商家廠區交集篩選，並去重廠區資料。

可見性流程

1. 員工登入

API 透過 JWT 或測試 header 取得 employee_id。

2. 查廠區

從 employee_facilities 找員工所屬廠區。

3. 比對商家

商家必須同時是 approved 且有共同 facility_id。

4. 回傳或拒絕

符合者可瀏覽與下單，不符合者以 404 隱藏。
